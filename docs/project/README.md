# Project

What this project is, why it exists, and the decisions behind it. Architecture, constraints, product rules, business logic.

## Records

One file per durable decision. Copy the template below.

### ADR template

```md
# ADR-0000: <short title>

- Status: proposed | accepted | superseded
- Date: YYYY-MM-DD

## Context

What forces this decision.

## Decision

What was chosen.

## Consequences

What gets easier / harder.
```
